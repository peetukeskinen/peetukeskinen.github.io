# papers/

PDFs served from the site live here: working papers, appendices, slides and the CV.

Keep filenames lowercase and hyphenated, e.g. `eu-fiscal-rules-multiple-equilibria.pdf`.

Link to them with a relative path from the page that references them:

```html
<a href="papers/eu-fiscal-rules-multiple-equilibria.pdf">PDF</a>
```

This directory is tracked so the folder exists in the repository; the file itself is
not published as a page.
